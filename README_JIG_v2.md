# 정적 가압 지그 v2 (지름 22 mm 케이스형 압전 버저용)

## 왜 정적 가압인가

| | v1 낙하추 | v2 정적 가압 |
| --- | --- | --- |
| 입력 | 약 70 g 추를 떨어뜨리는 충격 | 1–5 kg 추를 받침판에 천천히 올렸다 내림 |
| 알 수 있는 값 | 낙하 에너지 mgh만 (충돌 힘은 모름) | 가한 힘 F = mg |
| 신호 | 3 kHz 공진 울림이 섞임 | 발걸음과 같은 준정적 입력 |
| 검증할 수 있는 관계 | 같은 입력의 반복성 | V ∝ F, 에너지 ∝ F² |

## 파일

| 파일 | 내용 |
| --- | --- |
| `out/jig2_01_base.stl` | 하판 60 × 60 × 8. 버저 포켓 Ø22.4 × 깊이 4, +x 배선 홈, −x 꺼내기 홈, M3 구멍 4개 |
| `out/jig2_02_bridge.stl` | 다리 4개 달린 상판 + 축 슬리브(내경 12.5, 높이 25) |
| `out/jig2_03_plunger.stl` | 중앙 돌기 Ø6 + 축 Ø12 + 추 받침판 80 × 80 + 원판 추 중심 기둥 Ø24. **출력 방향으로 뒤집어 저장됨** |
| `out/jig2_00_assembly_check.stl` | 조립 확인용 (출력하지 말 것) |
| `out/jig2_section.png` | 단면도 |
| `piezo_jig_v2.py` | 생성 스크립트. 상단 상수만 고쳐 다시 실행 |
| `section_drawing_v2.py` | 단면도 생성 |

간섭 검사: 하판·브리지·플런저·버저 사이 겹침 0 mm³ (스크립트 실행 시 출력).

## 출력 전에 반드시 고칠 값

`T_CASE = 7.0` (버저 두께)은 **가정값**이다. 자로 버저 두께를 재서 고친 뒤 다시 실행한다.
두께가 가정보다 얇으면 플런저가 더 내려가는데, 받침판과 슬리브 사이 여유가 5 mm(`GAP_TRAVEL`)뿐이어서 5 mm 넘게 얇으면 받침판이 슬리브에 걸려 힘이 버저에 전달되지 않는다.

## 조립

1. 하판 포켓에 버저를 넣고 선을 +x 배선 홈으로 뺀다.
2. 브리지를 올리고 M3 × 30 볼트와 너트 4개로 하판에 고정한다.
3. 플런저 축을 슬리브 위에서 넣어 돌기가 버저 중앙에 닿게 한다.
4. 받침판에 추를 올린다. 아령 원판은 중심 기둥에 끼우고, 물병·모래주머니는 받침판 가운데에 놓는다.

## 측정할 때

- 가한 힘 = (추 무게 + **플런저 무게**) × 9.8. 플런저는 출력 후 저울로 재서 기록한다(PLA 100 %면 약 56 g, 인필에 따라 가벼움).
- 추는 매번 같은 속도로 천천히 올리고 내린다. 올릴 때와 내릴 때 펄스가 반대 방향으로 나온다.
- 조건(추 무게)당 10회 이상, CSV에 `mass_kg` 열을 추가해 기록한다.
- 버저 신호는 압전 진동 센서 모듈을 거친다. 모듈의 1 MΩ 저항이 병렬로 걸려 있는지 멀티미터로 먼저 확인한다.

## 출력 설정

- PLA, 레이어 0.2 mm, 인필 40 % 이상 (플런저 축은 100 % 권장)
- 하판: 바닥면이 아래 / 브리지: 상판이 아래(슬리브가 위) / 플런저: 저장된 방향 그대로(받침판이 아래)
- 서포트 불필요

## 한계

- 케이스형 버저는 내부 디스크의 지지 방식이 케이스로 정해져 있어 "바닥 놓기 vs 테두리 지지" 비교는 이 지그로 할 수 없다. 그 비교는 맨 디스크를 따로 구해 v1 지그를 실물 치수로 고쳐서 한다.
- 돌기가 케이스 윗면을 누르므로, 힘이 내부 디스크에 얼마나 전달되는지는 케이스 구조에 따라 다르다.
